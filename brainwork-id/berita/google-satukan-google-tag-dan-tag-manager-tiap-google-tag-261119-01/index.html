Google satukan Google tag dan Tag Manager: tiap Google tag kini jadi container

Google menyatukan Google tag dan Google Tag Manager: tiap Google tag kini menjadi Tag Manager container.

  1. Uji coba
  2. Bertahap
  3. Semua user

Status rilis: Bertahap

Dilaporkan oleh Google Tag Manager Help, rilis 17 Nov 2026

Poin utama

  • Lewat release note 17 November 2026, Google menyebut semua kemampuan Tag Manager dibawa ke Google tag. Website yang hanya memakai Google tag bisa memakai fitur tagging berbasis antarmuka, debugging, dan version control.
  • Perilaku tag di halaman tidak berubah. Tiap destination Google punya tag sendiri, sehingga setup dan trigger yang ada tetap dipertahankan. Akses data Tag Assistant kini mengikuti permission container Tag Manager.
  • Snippet pemasangan baru akan seragam dan tidak lagi memuat perintah gtag config. Google menyarankan mengatur initialization lewat Initialization trigger, yang juga bisa dibuat menunggu perintah config untuk mempertahankan setup lama.

Artinya buat advertiser: website yang hanya memakai Google tag kini punya opsi memakai fitur Google Tag Manager, tanpa perubahan perilaku tag di halaman.
