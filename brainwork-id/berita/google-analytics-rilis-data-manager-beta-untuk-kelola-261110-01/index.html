Google Analytics rilis Data Manager beta untuk kelola data stream dan link produk

Google Analytics merilis Data Manager (beta), pusat pengelolaan data di menu Admin untuk link produk, data stream, dan data first-party.

  1. Uji coba
  2. Bertahap
  3. Semua user

Status rilis: Masih uji coba

Dilaporkan oleh Google Analytics Help, rilis 6 Nov 2026

Poin utama

  • Data Manager memusatkan pengelolaan link produk, data stream, dan data first-party, plus peringatan diagnostik dan pemantauan kesehatan koneksi.
  • Tersedia peta koneksi data untuk melihat alur sumber data, property, dan tujuan ekspor, serta penanda error setup dan celah measurement.
  • Data mengalir dari Google Analytics ke akun Google Ads dan Google Marketing Platform yang terhubung, tidak sebaliknya.

Artinya buat advertiser

Google meminta pipeline data yang identik tidak diaktifkan di dua tempat sekaligus karena conversion bisa tercatat dua kali.
