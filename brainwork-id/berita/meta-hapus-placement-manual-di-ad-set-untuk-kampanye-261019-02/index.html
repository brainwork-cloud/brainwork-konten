Meta hapus placement manual di ad set untuk kampanye Sales, Leads, Engagement, dan App

Meta menghapus pilihan placement manual di level ad set untuk kampanye Sales, Leads, Engagement, dan App promotion.

  1. Uji coba
  2. Bertahap
  3. Semua user

Status rilis: Bertahap, belum tentu tampil di semua akun

Dilaporkan oleh Social Media Today & Relevant Audience, rilis 12 Okt 2026

Poin utama

  • Untuk objektif tersebut, pengiklan tidak lagi memilih placement secara manual di ad set. Awareness dan Traffic masih bisa.
  • Penggantinya: kustomisasi media per placement, placement value rules (menaikkan atau menurunkan bid per placement), dan pengecualian placement di level akun per objektif.

Artinya bagi pengiklan

Kontrol penempatan kini diatur lewat pengaturan akun, value rules, dan kustomisasi media.
